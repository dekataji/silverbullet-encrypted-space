# Encrypted Space 🔒

End-to-end encrypted notes for SilverBullet v2. See the
[README](https://github.com/dekataji/silverbullet-encrypted-space#readme) for full docs.

## Quick start

1. Run **`Plugs: Reload`** after this library is installed.
2. **`Encrypted Space: Unlock`** — enter your master password (once per session).
3. **`Encrypted Space: New note`** — create an encrypted note.
4. **`Encrypted Space: Lock`** — or just close the browser tab.

**Lost password = lost data.** There is no recovery.
